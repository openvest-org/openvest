# OpenVest

Uma plataforma aberta e gratuita para quem estuda para os vestibulares brasileiros.

O projeto está em estágio inicial.

## Deploy rápido

Clone o repositório, instale as dependências e inicie o ambiente local:

```bash
pnpm install
pnpm dev
```

Verificações disponíveis:

```bash
pnpm lint
pnpm typecheck
pnpm build
```
